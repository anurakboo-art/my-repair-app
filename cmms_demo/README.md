# CMMS Streamlit Demo

ทดลอง 6 เมนูโดยไม่แตะต้องแอปเดิมที่ root `app.py`.

Run: `pip install -r cmms_demo/requirements.txt` then `streamlit run cmms_demo/app.py`.

Streamlit Cloud main file path: `cmms_demo/app.py` on branch `feature/cmms-streamlit-demo`.

**Demo only:** records are stored in Streamlit session state; uploaded media are counted but not persisted. No login, durable storage, or access control yet. Do not enter real confidential data.
